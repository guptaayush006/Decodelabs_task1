# 📝 To-Do List Application

## Decode Labs Python Programmer Internship - Task 1

### 📌 Overview
This repository contains Task 1 of my Decode Labs Python Programmer Internship.

The project is a simple command-line To-Do List Application built using Python. It allows users to add tasks, view their task list, and manage daily activities through an easy-to-use menu-driven interface.

---

## 🚀 Features
- ➕ Add new tasks
- 📋 View all saved tasks
- 🔄 Menu-driven interface
- ❌ Exit the application safely
- ✅ Beginner-friendly Python implementation
